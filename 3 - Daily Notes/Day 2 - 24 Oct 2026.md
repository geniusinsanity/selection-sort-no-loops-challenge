## Entry 6: Reviewing Code & Detecting Weaknesses (AI Pair Programming)

- **Time:** Evening
- **Tool / medium:** AI Assistant (Antigravity)
- **Place / source:** Local code review of `version4.cpp`
- **Goal:** Identify potential bugs and weaknesses before the teacher reviews the project.
- **What was found:**
  1. **Memory Leak:** `new Inner[n - i - 1]` allocated heap memory without `delete[]`. In an array of size $N$, it allocates heap memory $N(N-1)/2$ times without freeing!
  2. **Imperfect Swap:** `swap(int &x, int &y)` ignored its parameters and used global variables.
  3. **Remaining Loops in main():** The sorting function was loop-free, but printing in `main()` still used a `for` loop. The teacher might reject it on a technicality.
- **Solution:** 
  - Wrote `version5.cpp` with `delete[] new Inner[...]` and clean `swap`.
  - Wrote `final_version.cpp` introducing `struct Printer` so that even array printing has 0 loops across the entire program.
- **What I learned:** Even clever tricks must be memory-safe and clean.

## Entry 7: Exploring Alternative Solutions (What if the teacher wanted C or Pseudo-code?)

- **Time:** Evening
- **Tool / medium:** Research & C Standard Library Analysis
- **Goal:** Find out how this PhD challenge could be solved in pure C or theoretical pseudo-code (where C++ constructors don't exist).
- **Results found:**
  1. **Pure C solution (`setjmp` / `longjmp`):**
     - In C, `<setjmp.h>` allows non-local jumping without `goto`, `loops`, or `recursion`.
     - Created `4 - The Program/alternative_c_setjmp.c` and proved it works!
  2. **Theoretical / Pseudo-code solution (Boolean Comparison Matrix):**
     - In PhD algorithmic theory, sorting without sequential loops is expressed as a Boolean Comparison Matrix $B[i][j] = (A[i] > A[j])$.
     - Counting the `true` values in each row gives the exact final rank of each element without iterative swapping.
- **What I learned:** If the professor intended C, `setjmp`/`longjmp` is the secret. If the professor intended C++, constructors are the secret. If theoretical pseudo-code, Boolean matrices are the secret.
